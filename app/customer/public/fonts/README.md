# Local font assets

The unmodified font binaries identify their family and copyright holders in their embedded name tables. Material Symbols Outlined provides icons; Plus Jakarta Sans provides body weights; Archivo Expanded ExtraBold and DM Sans provide the header. Inter PDF fonts are supplied by pinned @fontsource/inter, including its package license.
