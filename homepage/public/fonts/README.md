# Local homepage fonts

Unmodified font binaries are served locally. Existing Material Symbols Outlined, Plus Jakarta Sans (400–700) and Archivo Expanded ExtraBold are copied from the invoice application assets. Their original provenance and fingerprints are documented in app/customer/public/fonts/README.md. Corresponding redistribution licenses are retained here.

The approved homepage also uses JetBrains Mono (400, 500, 600) and Plus Jakarta Sans 800. These unmodified binaries were obtained from Google Fonts. Family/copyright metadata remains embedded.

Stylesheet source: https://fonts.googleapis.com/css2?family=Plus+Jakarta+Sans:wght@800&family=JetBrains+Mono:wght@400;500;600&display=swap

JetBrains Mono license source: https://raw.githubusercontent.com/google/fonts/main/ofl/jetbrainsmono/OFL.txt
